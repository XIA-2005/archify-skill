# Archify 定制增强版

这一版基于 [tt-a1i/archify](https://github.com/tt-a1i/archify) **3.1.0**，在原版图表生成、验证和独立 HTML Viewer 上，扩展了**十种图表类型、draw.io 原生线条与框架编辑、透明背景导出、可选帧率的 PPT 动图和高分辨率导出**。这是 XIA-2005 维护的独立定制版，保留原作者与 MIT 许可证。

**源码位置：** 本仓库 `main` 分支的根目录就是可安装的 Archify Skill，包含 `SKILL.md`、运行时模板、可视化编辑器、示例和交付脚本。

## 与原版相比，更新了什么

| 功能 | 原版基础与本版变化 | 实际用途 |
| --- | --- | --- |
| 可视化编辑器 | 在原版 Viewer 的查看与导出之外，增加匹配当前图表的本地编辑入口。Architecture 支持拖动模块、编辑文字和连线、撤销/重做、对齐、布局预览及导航 | AI 生成后直接调整图表，不必手工改 JSON |
| 强制交付编辑入口 | Skill 交付规则扩展为正式 HTML、可编辑 JSON，以及实际运行的匹配编辑器地址 | 每次交付都能继续修改，编辑器和正式图使用同一份数据 |
| 点击编辑连线文字 | 点击连线标签即可进入属性编辑，独立修改内容和字号，支持键盘、撤销与重做 | 修改标签时保留连接端点和路由 |
| draw.io 原生线条与框架操作 | Architecture 画布集成固定版本的 draw.io Desktop 编辑引擎，支持原生端点/折点、连接箭头、框选、多选与框架缩放；不兼容 Archify schema 的样式会阻止保存 | 使用熟悉的图形编辑操作，同时避免不支持的变更被静默丢弃 |
| 按文字类型批量改字号 | 增加模块名称、说明、标签、连线文字、分组标题、图例文字、说明卡片标题及正文八类控制 | 一次调整同类文字，避免逐个模块修改 |
| 悬停高亮定位 | 批量字号列表支持悬停、键盘焦点预览，标出对应文字和所属模块、连线、分组、图例或卡片 | 看清每个文字类型控制哪些元素；预览不会修改字号或图表 |
| 编辑器浅色模式 | 原版 Viewer 的主题之外，编辑器界面和画布也可切换浅色/深色，同一浏览器地址记住选择 | 属性面板、小地图、文字、节点和连线随主题切换 |
| 默认折叠低频设置 | 将主标题、副标题、图例标题的内容/字号及输出校验标准收进“标题、图例与输出设置” | 给常用文字编辑与模块属性留出空间，需要时展开 |
| 标签底色透明 | 连线文字和分组/虚线框标题不再绘制遮挡元素的标签底色 | 放大文字时减少遮挡；节点填充、连线原有遮罩和跨线处理保留 |
| 导出可选透明背景 | PNG、WebP、PNG 剪贴板、WebM、GIF，以及 SVG 自动/浅色/深色新增统一透明背景选项 | 插入 PPT 或其他有背景的文档时更好融合；SVG 透明导出移除画布底色和背景网格，保留节点填充 |
| GIF 动图导出 | 在已有图像、SVG、WebM 导出之外增加循环 GIF，单次同步通过，信号流速度 2–6 秒可调（默认 4 秒），导出前可预览；默认 12 fps，菜单可选 12/24/30/50 fps，静态图也能导出连线追踪动画 | 插入 PPT 后以动图展示流程；GIF 最多 256 色，使用二值透明 |
| GIF 信号模式 | 导出可选「同时流动」或「接力传递（跟随页面 Live 到达顺序，分支可并行）」；预览与导出共用同一模式；无连线时序时提示不可用 | 按页面到达顺序演示信号流程，分支可并行；无可用时序时明确提示不可用 |
| 导出放大倍数 | 图片、PNG 剪贴板、GIF、WebM 提供默认 / 1× / 3× / 5× / 7× / 10×，按目标分辨率重新渲染 | 改善栅格图片和动图放大后的清晰度；SVG 本身保留矢量，倍率不作用于 SVG |
| 分组标题独立偏移 | 增加分组标题位置调整，边框和连线路径不随标题一起移动 | 给标题避让空间，保持系统分组与连接关系 |
| 十种图表类型（3.1.0） | 在 Architecture / Workflow / Sequence / Dataflow / Lifecycle 之外，增加 ERD、Class、Tree、Timeline、Waterfall，均支持 typed JSON 与独立 HTML Viewer | 用同一套交付流程覆盖更多结构与时间线场景 |
| 多语言 Viewer 目录 | 内置 en / zh-CN / zh-TW / es / ko 等语言包，按 `meta.locale` 选择 | 导出与阅读界面可切换语言，繁体中文不再回退到英文 |
| Live 动效默认可读 | 各图类型配有匹配的动效编排，读者可切到 Still；动效与拓扑、导出几何分离 | 演示时有动效，导出仍保持清晰静态/可控 GIF |
| 连线动效跟随原色 | 悬停脉冲、Intent Trace、环境流等装饰线读取连线实际描边色（含主题/预设切换），通过 `--flow-stroke` 同步 | 彩色或主题化连线上的信号不再一律用强调色 |
| Architecture draft 入口 | 增加从语义输入生成布局候选的入口，候选仍须经过正式验证和视觉验收 | 辅助生成第一版布局，不以自动布局替代最终审查 |

这张表包括此前的可视化编辑扩展，以及本仓库新增的导出和易用性改进；并非所有能力都由最后一个提交单独引入。

## 怎么使用这些新增功能

1. **编辑图表：** 让 AI 使用本版 [SKILL.md](SKILL.md) 生成图表，并提供正式 HTML、JSON 和本地编辑器链接。Architecture 使用完整图形编辑器；其他四种图使用字段/JSON 编辑器。
2. **修改连线标签：** 点击画布上的连线文字，在属性面板修改内容和字号。修改暂存在浏览器中，点击“保存并生成 HTML”才写入文件。
3. **整体修改字号：** 展开“按文字类型设置字号”，打开文字类型列表并悬停定位目标，选择类型、输入字号，再点“应用到该类型”。移开鼠标、关闭列表或按 Esc 可清除高亮。
4. **切换编辑器主题：** 点击顶部“浅色模式 / 深色模式”。编辑器主题不会修改 JSON 或正式导出的主题。
5. **用于 PPT：** 在“导出图像”窗口选择 GIF 动图，再选 12、24、30 或 50 fps（默认 12 fps）及所需倍率。静态图可选择 SVG；需要背景融合时勾选“透明背景”，然后选择 SVG 自动/浅色/深色或支持透明的栅格/动图格式。
6. **调整标题：** 展开“标题、图例与输出设置”。主标题、副标题、图例标题字号与模块文字独立；副标题留空则不显示。Showcase / Standard 是保存时的校验标准，导出清晰度请用放大倍数控制。

详见 [编辑器操作文档](editor/README.md)、[Viewer 运行时文档](references/viewer-runtime.md) 和 [定制版本记录](LOCAL_CUSTOMIZATION.md)。

## 保留了哪些原版行为与限制

- 原版五类图表、typed JSON、正式渲染器、校验、来源检查和独立 HTML 输出继续使用。保存时备份 JSON 并走正式校验；自动检查与人工视觉验收是不同阶段。
- 完整拖拽编辑目前只针对 Architecture v1。Workflow / Sequence / Dataflow / Lifecycle 提供字段和 JSON 编辑，不宣称支持同等图形拖拽能力。
- 编辑器只绑定本机 localhost；链接仅在对应 Node 服务运行时有效。本机编辑器不是部署在 GitHub 上的在线编辑服务。
- JPEG 不支持透明背景；GIF 的透明度为二值，颜色最多 256 种。显式导出倍率超过尺寸上限时会提示降低倍率。
- 更大倍率增加像素尺寸、导出时间和文件体积。SVG 保持矢量；PPT 的 SVG/GIF 支持取决于实际版本及播放环境。
- 本版并未移除节点填充，也未将连线原有遮罩改成透明。只移除标签底色，并在用户勾选导出透明背景时移除画布背景。
